# Как менять контент

## Маркетинговый текст

Откройте `src/content/landing/ru.mdx`. Пять секций идут в том же порядке, что и на странице:

1. `HeroSection`;
2. `PainSection`;
3. `BenefitsSection`;
4. `ProductSection`;
5. `OfferSection`.

H1 и утверждённый подзаголовок менять только после отдельного продуктового решения.

## Значения интерфейсного примера

Время, продолжительность сна, следующий интервал и объяснения находятся в `src/content/landing/demo.ru.yaml`. Hero и центральный мокап читают один файл, поэтому значения не расходятся.

Пока output не сверен с MVP, оставляйте `status: illustrative`.

## После правки

```bash
pnpm format
pnpm validate
```

Особенно проверяйте `docs/reports/proportions.md`: новый объём текста может изменить высоту секции. Для коррекции сначала меняйте реальные модули, responsive gap и section padding. Не добавляйте пустые spacer-блоки и не скрывайте текст.

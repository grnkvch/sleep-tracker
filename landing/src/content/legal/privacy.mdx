# Конфиденциальность

<p className="draft-badge">Черновик — требуется проверка владельцем продукта</p>

Эта страница относится только к маркетинговому лендингу. В базовой версии лендинг не содержит форм для сведений о ребёнке и не сохраняет данные о сне.

## Что может передаваться при переходе

Кнопки ведут в выбранный канал продукта. В будущем при переходе могут сохраняться только рекламные метки источника — без имени, возраста ребёнка, записей сна и другой чувствительной информации.

## Внешние сервисы

Конкретная система аналитики и рекламные пиксели пока не выбраны и по умолчанию не подключены.

Перед публикацией сюда нужно добавить подтверждённые сведения об операторе данных, контактах, сроках хранения и фактической обработке данных внутри продукта.
